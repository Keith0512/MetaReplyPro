# 擴充功能圖示設計

日期：2026-07-14
狀態：使用者已選定 F 方案（護目鏡閃電機器人）

## 問題

manifest 沒有設定 `icons` 與工具列 `action.default_icon`，Chrome 只顯示灰色拼圖預設圖。

## 設計

- **視覺**：靛藍（#4F46E5）圓角方塊為機器人頭、白色護目鏡橫帶＋深靛藍（#312E81）雙眼、
  頂部白色天線、琥珀色（#FBBF24）閃電。為小尺寸清晰度重新設計：臉佔滿畫面、元素加大、
  無細線條（第一版 C 方案細節過多，16px 模糊，經使用者反饋後改版）。
- **產出流程**：`chrome-extension/icons/icon.svg` 為原稿（進版控），
  以瀏覽器 canvas 轉出 icon16/32/48/128.png。日後改圖改 SVG 重轉即可。
- **manifest**：`icons` 與 `action.default_icon` 各列四種尺寸；版號 1.4.1。

## 驗收

1. chrome://extensions 清單、工具列按鈕、擴充功能管理頁都顯示新圖示（不再是灰拼圖）。
2. PNG 尺寸標頭正確（16/32/48/128）。
